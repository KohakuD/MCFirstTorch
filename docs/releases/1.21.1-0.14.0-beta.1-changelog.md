First Torch is now available for Minecraft **1.21.1**, using **NeoForge 21.1.248** and **Java 21**.

- Step-by-step survival lessons in English and German, from early survival to the Nether, End and independent exploration.
- Native quest browser, automatic and manual tasks, rewards, trophies, search and a reference library.
- Lessons, recipes and available items adapted to Minecraft 1.21.1, including Iron armour and the Netherite lodestone recipe.
- First Torch opens from its shortcut key or the pause-menu entry, positioned above the normal buttons when space permits.
- Native game illustrations and the approved shared course screenshots.

Install only this Minecraft 1.21.1 file in a NeoForge 1.21.1 profile. No FTB dependencies or separate guide resource pack are required. Back up existing worlds before updating; downgrading newer Minecraft worlds is not supported.

This is a Beta. Dedicated-server operation remains unverified. Minecraft 26.2 support and the returning-learner version filter will follow in later releases.
