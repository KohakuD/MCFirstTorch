# First Torch 0.14.0 — Minecraft 26.2

- First Torch is now available for Minecraft 26.2 with its native bilingual quest browser, guided survival course and reference library.
- Add five Sulfur Caves reference cards covering navigation, gas and geysers, hanging spikes, Sulfur Cubes and building materials, with reading links and a trophy.
- Add Friends List guidance to the reading introduction.
- Returning learners can select Minecraft 1.21.1 or 26.1.2 to see cumulative new and revised lessons. Each card explains its specific change.
- Use the Clock icon to switch back to all quests. Your selection is remembered locally per player and Minecraft version.
- Background links provide access to prerequisite explanations. Selecting prior knowledge never completes quests or grants rewards.
- Add a wide First Torch banner in the mod overview, correct the loader icon metadata and fix a creature-preview crash.
- Remove outdated development wording from the introduction.

Requires Minecraft Java 26.2, NeoForge 26.2.0.86 and Java 25. Use the matching Minecraft edition of First Torch; this release does not downgrade worlds or import progress between Minecraft versions.
