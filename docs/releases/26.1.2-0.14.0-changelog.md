# First Torch 0.14.0 — Minecraft 26.1.2

- Returning to First Torch? Choose Minecraft 1.21.1 in the welcome dialog to see new and revised lessons since that edition.
- Use the Clock icon to change your selection or return to all quests. Your choice is remembered locally for your player and Minecraft version.
- Each comparison lesson explains what changed, including Copper armour, the cheaper Lodestone recipe and the Creaking reference.
- Follow background links when you need a refresher, then return to the comparison. Quest completion and rewards remain shared between views and are never granted simply for selecting prior knowledge.
- Remove outdated development wording from the introduction.

Requires Minecraft Java 26.1.2, NeoForge 26.1.2.84 and Java 25. Use the matching Minecraft edition of First Torch; this release does not downgrade worlds or import progress between Minecraft versions.
